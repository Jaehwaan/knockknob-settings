# KnockKnob 설정 페이지

책상 노크와 회전 노브로 컴퓨터를 조작하는 블루투스 입력 장치 **KnockKnob**(졸업작품)의 설정 페이지입니다.

**열기:** https://jaehwaan.github.io/knockknob-settings/

## 쓰는 법

1. KnockKnob을 USB 케이블로 컴퓨터에 연결합니다.
2. PC의 **Chrome** 또는 **Edge**에서 위 주소를 엽니다(Safari·휴대폰 브라우저는 지원하지 않음).
3. ‘보드 연결(USB)’ → 목록에서 장치 선택 → ‘연결’.
4. 값을 바꾸고 ‘적용’(시험) 또는 ‘보드에 저장’(전원을 꺼도 유지). ‘처음 값으로’는 출고 설정으로 되돌립니다.

평소 사용에는 이 페이지가 필요 없습니다. 장치는 블루투스 키보드로 연결되어 동작합니다.

## 개인정보

이 페이지는 브라우저 안에서만 동작합니다. 장치와는 컴퓨터의 USB로만 통신하며, 어떤 정보도 인터넷으로 보내지 않습니다.
